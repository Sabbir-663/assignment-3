# Project name : Library management system

## Technologies Used: Express.js, mongoDB, mongoose, typescript

### Key Features : 

1.Creating a book with relevant information

2.Get all books 

3.Find single book by id

4.Update a book

5.Delete a book

6.Borrow a book if the book's copy is available

7.Find all the borrow's books

### RUN
For locally run : npm run dev
